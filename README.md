Entry for the [Tell a Whole Story in 32 Characters bounty on make.fun](https://make.fun/competitions/u-xvader-tell-a-whole-story-in-32-characters-f86dd978).

One Wi-Fi network name, 32 characters, that lands a joke and implies a whole story: a breakup told as an asset split.

> She took the dog, left the Wi-Fi

`main.py` (stdlib only, python3.13) writes the name to `/output/entry.txt`, self-checks the 1–32 character gate, and reads the file back to confirm the round-trip. Run `python3 main.py --check` to validate without writing.
